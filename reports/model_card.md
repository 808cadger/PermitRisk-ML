# Model Card: PermitRisk-ML

## Intended use

Early screening for permit-delay risk in construction workflows. The model is a prioritization aid, not an approval or rejection system.

## Data

The included dataset is synthetic and generated by `permitrisk_ml.make_dataset`. It is useful for demonstrating workflow quality, feature handling, and evaluation discipline.

## Features

- Permit type
- Zoning context
- Project value
- Missing document count
- Reviewer queue size
- Prior revision count
- Contractor prior approval count

## Evaluation

The project compares the risk model against a majority-class baseline on a held-out test split. Metrics are regenerated with:

```bash
python -m permitrisk_ml.train
```

## Limitations

- Synthetic data cannot prove real-world predictive performance.
- Real deployment would require historical permit data, leakage review, fairness review, and monitoring for drift.
- The output should be used to prioritize review support, not to deny service or create hidden administrative barriers.
